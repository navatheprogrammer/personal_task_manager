# Personal Task Manager

![Personal_Task_Manager_Badge](https://img.shields.io/badge/python-pink?logo=python&logoColor=white
)
A simple task manager built with python



## Features
- add multiple tasks
- save tasks
- load saved tasks
- Admin Mode


## Reaquierments
- python
- python-dotenv

## Installation

install requiered pakage:

```bash
python -m pip install -r requierments.txt
```


## Enviorment setup

createa `.env` file in the project folder

use `.env.example` as a template

add your admin password


```env

admin_passwrod_password_here
```

replace `your_password_here` with your own admin password


## tun the program
run main file

```bash
python main.py
```
